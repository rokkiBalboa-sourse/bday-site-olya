# 🐕 Интерактивная Открытка с Днём Рождения и Корги (SPA)

Современный, чистый и минималистичный Single Page Application (SPA) на **Next.js**, **React**, **Tailwind CSS** и **Framer Motion**.

## 🎨 Особенности и Дизайн
- **Kumo UI Aesthetic**: Лаконичная типографика, продуманные отступы, границы `border-amber-200`, эффекты матового стекла (`backdrop-blur-md`), скругления `rounded-3xl` и лёгкие праздничные тени.
- **Цветовая палитра**: Рыжий Корги (`#f59e0b`), праздничный коралловый (`#ff6b6b`), мятный (`#4ebd98`) и золотисто-жёлтый (`#fcd34d`).
- **Тема Корги**: Векторный анимированный Корги с колпачком, машущий хвостиком, бегающие глазками и язычком.
- **Пользовательский сценарий (User Flow)**:
  1. Экран приветствия с возможностью ввода имени и даты рождения.
  2. Интерактивная кнопка «Получить сюрприз 🎁».
  3. Анимация переключения экранов с эффектом салюта-конфетти (`canvas-confetti`).
  4. Экран поздравления с Днем Рождения.
  5. Главный подарок — стилизованный билет на концерт с штрихкодом, деталями посадки и кнопкой **«Скачать PDF»** (ссылка на `/ticket.pdf` с атрибутом `download`).

---

## 🛠 Запуск Проекта

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер разработки:
```bash
npm run dev
```

3. Откройте в браузере: `http://localhost:3000`

## 📝 Как подставить свои данные и файлы

### 1. Как вставить свою картинку Корги:
* Положите ваш файл изображения (например `my-corgi.png`) в папку `/public`.
* Откройте файл `app/page.tsx` или `components/TicketCard.tsx` и передайте проп `customImageUrl="/my-corgi.png"` в компонент `<CorgiIllustration />`:
```tsx
<CorgiIllustration customImageUrl="/my-corgi.png" className="w-36 h-36" />
```

### 2. Как заменять PDF-файл билета:
* Положите ваш реальный PDF билет в папку `/public/ticket.pdf` (или дайте ему любое имя, например `/public/my-concert-ticket.pdf`).
* В компоненте `components/TicketCard.tsx` или в `app/page.tsx` измените проп `pdfUrl="/my-concert-ticket.pdf"`.
